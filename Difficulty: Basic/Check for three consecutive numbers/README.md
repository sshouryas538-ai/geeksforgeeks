<h2><a href="https://www.geeksforgeeks.org/problems/check-for-three-consecutive-numbers5729/1">Check for three consecutive numbers</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p class="PDq2pG_selectionAnchorContainer" data-start="186" data-end="287"><span style="font-size: 14pt;">Given an integer <strong>n</strong>, determine whether it can be expressed as the sum of three consecutive integers. </span></p>
<p class="PDq2pG_selectionAnchorContainer" data-start="186" data-end="287"><span style="font-size: 14pt;">If possible, return the three consecutive integers in increasing order. Otherwise, return <strong>-1</strong>.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input</strong>: n = 6
<strong>Output:</strong> [1, 2, 3]&nbsp;
<strong>Explanation</strong>: 6 = 1+2+3 Hence 6 can be written as sum of three consecutive integer.
</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>n = 7
<strong>Output:&nbsp;</strong>-1
<strong>Explanation</strong>: 7 cannot be written as sum of three consecutive integer.
</span></pre>
